# Try-out of one whole day, 2026-11-18

**Paper money only. This was a try-out by the session that built the code: none of it counts, and its records
are not part of the pilot's log.** No company is named here and nothing here comes from prices.

## What was run
One daily round from start to end, on the data saved up to that evening, with the Careful fund only.

- It ran in a data folder of its own, next to the real one, so the pilot's log starts clean on day 0.
- Every record of the round carries the mark "dry run by the building session, with stand-in agents; its trades
  never count" (12 of the 13; the record that started the fund has none).
- **The agents were stand-ins.** Claude Code only loads a new agents folder when a session starts, and the folder
  was made in this very session. Each stand-in was a general agent started on the role's model and effort, with
  the role's instructions put in front of its task. A stand-in has no tool list of its own and no reading check,
  so the script's own check of each agent's record was the only guard. That check did its work (see below).
- The session was not fresh and the code was not merged; the script noted both and went on only because this
  was a try-out. The step clock was noted, not enforced.
- Before this, the whole day ran once with recorded answers and no model at all; every step passed.

A first session of a month analyses two companies, not four. A day with four companies would start 20 analyst
runs side by side; the longest single analyst run took about two minutes, so step 4 should still end well inside
its time.

## What the round produced
- Screening: 186 companies had news; 86 were judged, 35 of them marked worth a deep look; 100 were not judged
  because their batches were thrown out (see below).
- Deep analysis: two companies, both first reports. One got a report (two usable sections); the other got none
  (one usable section is not enough) and so stays off the covered list.
- 10 forecasts written, all with a date and a probability.
- Decisions: all three runs were readable and all three said the same: one new position, at the same size. One
  order is waiting; it could not be filled in the try-out because the next trading day had not come.
- The log: 13 records in one unbroken chain; the books recomputed from it agree. The day page was written and
  committed on this machine only.

## What broke, and what was done
1. **11 of 21 answers were thrown away by the script.** 8 because a stand-in used the command line: in this
   session a general agent had no search tools, and a real agent file has the search tools and nothing else.
   1 because an agent searched without naming a folder, which a real agent could also do. The script refuses
   any answer whose agent used a tool other than reading inside the session folder; that is the rule working as
   meant. *Still to see on day 0: how often a real agent searches without a folder.*
2. **Two screening answers were thrown away for one extra field in one company's entry**, which cost two whole
   batches of 25 companies each. *Open:* either accept an unknown field in a screening entry, or keep it strict
   and see how often it happens with the real agent file. Recommended: wait for day 0, then decide.
3. **Agents could not list a folder**, and guessed file names. *Fixed:* an analyst's task now names every file of
   the company folder by its full path.
4. **Prices lag behind.** On the evening of the 18th the newest final price day was the 16th: the source marks
   its newest day "delayed", and the books use final copies only. A fill is therefore booked a session or more
   later than the calendar alone would allow. No rule is broken. *Open: see in the pilot when the final copy of
   a day arrives, and whether the lag matters.*
5. **What the agents missed most** (49 remarks): the trial records (not linked to companies yet: the owner's
   check of the review sheet), the design of trials that have not read out, the latest quarterly report (it was
   filed before the look-back of a first session), and an earlier report of our own (there is none on a first
   day).
6. **The review of the round's code** (an Opus reviewer, while the try-out ran) found twelve faults that the
   try-out itself did not hit, among them: a round that was published but never ended would have stopped the
   books of every later day. A second review checked those fixes and found two incomplete. All are worked in,
   most with a test (record 0003, "Review").

## Checked for real after the try-out
Later in the same session Claude Code did load the agent files. One real screening agent was started once, with
a request to read a file outside any session folder:
- it ran as its own agent type, on the exact model and the effort of its file (read from its record);
- **the reading check ran inside the agent and refused the read**;
- its report came back in the form the script reads.
